ASSET KENDARAAN JATIUWUNG
=========================
Project dasar website online.

Fitur:
- Mobil, Motor, Bentor/Roda Tiga
- Login 1 akun admin dari beberapa perangkat
- Dashboard jumlah kendaraan
- Pencarian
- Jatuh tempo/perpanjangan
- Pergantian kaleng/plat
- Dokumen STNK, BPKB, Berita Acara
- Pemeliharaan

LANGKAH:
1. Upload folder project ini ke GitHub.
2. Hubungkan ke Supabase.
3. Isi URL Supabase dan Publishable Key pada app.js.
4. Jangan pernah memasukkan Secret Key ke browser/GitHub.

File utama:
- index.html
- styles.css
- app.js
- supabase-schema.sql
